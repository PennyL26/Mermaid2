# Penny — Karate TRUE/FALSE Εξεταστική Εφαρμογή

Μια πλήρως λειτουργική, client-side web εφαρμογή ερωτήσεων τύπου TRUE/FALSE για
εκπαιδευτική/προπονητική χρήση στα αγωνίσματα **KUMITE** και **KATA**.

Χτισμένη με καθαρό HTML5, CSS3 και JavaScript ES6+ (ES Modules) — χωρίς
frameworks, χωρίς backend, χωρίς Java.

---

## 1. Απαιτήσεις συστήματος

- Οποιοσδήποτε σύγχρονος browser: Chrome, Edge, Firefox, Safari, Brave.
- Desktop (Windows/macOS) ή κινητό (Android/iOS).
- Ένας **web server** για την εκτέλεση της εφαρμογής (βλ. παρακάτω) — η εφαρμογή
  **δεν** λειτουργεί αξιόπιστα ανοίγοντας απευθείας το `index.html` με διπλό κλικ
  (πρωτόκολλο `file://`), επειδή οι browsers μπλοκάρουν τη φόρτωση τοπικών αρχείων
  Excel μέσω `fetch()` σε αυτή την περίπτωση.

## 2. Εγκατάσταση & εκτέλεση

Δεν χρειάζεται `npm install` — δεν υπάρχουν build steps. Η βιβλιοθήκη SheetJS
είναι ήδη ενσωματωμένη τοπικά στο `vendor/xlsx.full.min.js`.

Επίλεξε ένα από τα παρακάτω:

### Επιλογή Α — Python (προεπιλογή, δεν απαιτεί εγκατάσταση επιπλέον εργαλείων αν έχεις ήδη Python)
```bash
cd penny-app
python -m http.server 8000
```
Άνοιξε τον browser στο: `http://localhost:8000`

### Επιλογή Β — VS Code Live Server
1. Εγκατέστησε την επέκταση **Live Server** στο VS Code.
2. Άνοιξε τον φάκελο της εφαρμογής στο VS Code.
3. Δεξί κλικ στο `index.html` → **Open with Live Server**.

### Επιλογή Γ — Node.js (αν προτιμάς)
```bash
npx serve .
```

### Επιλογή Δ — GitHub Pages / οποιοδήποτε static hosting
Ανέβασε όλο τον φάκελο σε ένα repository και ενεργοποίησε το GitHub Pages
(Settings → Pages), ή ανέβασέ το σε οποιοδήποτε static hosting (Netlify, Vercel,
απλός Apache/Nginx κ.λπ.). Δεν απαιτείται καμία αλλαγή στον κώδικα.

Αν ανοίξεις το `index.html` απευθείας με διπλό κλικ (`file://`), η εφαρμογή θα
εμφανίσει σαφές μήνυμα που εξηγεί ότι χρειάζεται web server.

## 4. Πώς επεξεργάζομαι τις ερωτήσεις

Άνοιξε `data/qkumite.xlsx` ή `data/qkata.xlsx` με Excel/LibreOffice/Google
Sheets. Στήλες:

| A (Number) | B (Question)                          | C (Answer) |
|-----------|----------------------------------------|-----------|
| 1         | Η Αθήνα είναι η πρωτεύουσα της Ελλάδας. | TRUE      |
| 2         | Η Κρήτη βρίσκεται στον Ατλαντικό.       | FALSE     |

Κανόνες:
- Η πρώτη γραμμή είναι header και αγνοείται.
- Η στήλη A πρέπει να είναι θετικοί ακέραιοι, μοναδικοί, χωρίς κενά, ξεκινώντας
  από το 1 (1,2,3...N).
- Η στήλη C δέχεται μόνο `TRUE` ή `FALSE` (case-insensitive, επιτρέπονται κενά
  γύρω από το κείμενο).
- Μπορείς να προσθέσεις όσες ερωτήσεις θέλεις — δεν υπάρχει τεχνητό όριο.

Για το `mini-affirmations-mermaid.xlsx`, χρειάζονται μόνο οι στήλες A (αριθμός)
και B (κείμενο μηνύματος).

Αποθήκευσε το αρχείο **με το ίδιο όνομα, στον ίδιο φάκελο** — δεν χρειάζεται
καμία αλλαγή στον κώδικα.

## 5. Λειτουργίες

- Ανεξάρτητη φόρτωση/validation KUMITE και KATA — αν το ένα dataset είναι
  invalid, το άλλο συνεχίζει να λειτουργεί κανονικά.
- 3 τρόποι επιλογής ερωτήσεων: συγκεκριμένος αριθμός τυχαίων, όλες με τη
  σειρά, όλες τυχαία (unbiased Fisher-Yates shuffle).
- Ακριβής timer με βάση πραγματικό χρόνο (`performance.now()`), pause/resume.
- Swipe (κινητό) και click (desktop) για μετάβαση χωρίς απάντηση.
- Πλήρες πληκτρολόγιο: `Space`/`Enter` = Next, `T` = TRUE, `F` = FALSE,
  `P` = Pause/Resume, `Esc` = Home (με επιβεβαίωση), `Ctrl+Shift+/` = βοήθεια.
- Results screen με μηνύματα ανάλογα με το ποσοστό επιτυχίας, review λάθος/
  αναπάντητων ερωτήσεων, εξαγωγή αποτελεσμάτων σε CSV + TXT.
- Πλήρως offline μετά την πρώτη φόρτωση (Service Worker).
- WCAG 2.1 AA: keyboard navigation, focus states, ARIA labels, αντίθεση.

## 6. Επίλυση προβλημάτων (Troubleshooting)

**"Η εφαρμογή πρέπει να εκτελείται μέσω web server..."**
Άνοιξες το αρχείο με διπλό κλικ (`file://`). Χρησιμοποίησε μία από τις μεθόδους
της ενότητας 2.

**Τα KUMITE/KATA κουμπιά είναι απενεργοποιημένα**
Το αντίστοιχο αρχείο Excel είτε λείπει, είτε είναι κατεστραμμένο, είτε η
αρίθμηση των ερωτήσεων δεν σχηματίζει ακριβώς τη σειρά 1...N. Άνοιξε το αρχείο
και έλεγξε τις στήλες A, B, C.

**Δεν βλέπω τις ελληνικές ερωτήσεις σωστά / εμφανίζονται περίεργοι χαρακτήρες**
Βεβαιώσου ότι το αρχείο είναι πραγματικό `.xlsx` (όχι `.xls` ή CSV
αποθηκευμένο με λάθος encoding) και ότι το άνοιξες/αποθήκευσες με Excel ή
LibreOffice, όχι με απλό text editor.

**"Ζητήθηκαν Ν ερωτήσεις αλλά υπάρχουν μόνο Μ διαθέσιμες"**
Στις Ρυθμίσεις έχεις ζητήσει περισσότερες τυχαίες ερωτήσεις από όσες υπάρχουν
έγκυρες στο dataset. Μείωσε τον αριθμό ή πρόσθεσε περισσότερες ερωτήσεις στο
Excel.

**Η εφαρμογή δεν λειτουργεί offline**
Ο browser σου μπορεί να μην υποστηρίζει Service Workers, ή η πρώτη φόρτωση
έγινε μέσω `file://`. Η εφαρμογή θα συνεχίσει να λειτουργεί κανονικά online.

**Το κουμπί EXIT δεν κλείνει το παράθυρο**
Οι σύγχρονοι browsers δεν επιτρέπουν σε JavaScript να κλείσει ένα tab που δεν
άνοιξε η ίδια η JavaScript. Θα εμφανιστεί σχετικό μήνυμα — μπορείς απλά να
κλείσεις το tab χειροκίνητα.

**Οι ρυθμίσεις μου δεν αποθηκεύτηκαν**
Έλεγξε ότι ο browser σου δεν είναι σε "Private/Incognito" mode με
απενεργοποιημένο localStorage.
